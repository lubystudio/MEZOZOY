# Mezozoy 1.0.1

Mezozoy - нативное рабочее пространство для сценариста и подготовки истории на Windows 10/11 x64.

Приложение раз в шесть часов тихо проверяет последний выпуск в [официальном репозитории](https://github.com/lubystudio/MEZOZOY/releases). Если доступна более новая версия, внутри окна появляется плашка со ссылкой на страницу скачивания. Mezozoy никогда не загружает и не запускает обновления без действия пользователя.

Версия 1.0.1. Ручные сохранения выполняются атомарно, основной файл получает `.bak`-копию, дополнительные копии складываются в `Mezozoy Backups`, а автосохранение ведется отдельно в `*.autosave.mzoy`.

Программа полностью написана на C++20. Для запуска не нужны .NET, Java или отдельные библиотеки. Интерфейс использует Win32, карточная доска - Direct2D и DirectWrite.

## Установка

Для обычной установки скачайте `Mezozoy-1.0.1-Setup.exe` из раздела Releases. Также доступна переносная версия без установки.

## Запуск

Запустите `Mezozoy.exe` или откройте существующий `.mzoy` двойным щелчком. Приложение регистрирует текущий EXE как обработчик `.mzoy` только для текущего пользователя.

Проекты Mezozoy 0.8 открываются напрямую. Старый файл не меняется во время открытия и тестирования совместимости.

## Новое в 0.9

- новый главный экран текущего проекта: реальные метрики, быстрые действия, прогресс черновика, недавняя активность и последние сцены;
- единая широкая навигация и верхняя командная полоса с сохранением, поиском, отменой и повтором;
- архитектурный слой `WorkspaceHost`: панели регистрируются по стабильным ID, размещаются split-tree-компоновщиком и имеют минимальные размеры;
- текущая раскладка намеренно использует одну рабочую область, но фундамент готов для будущего деления, объединения и смены типа панелей в стиле Blender;
- после глобальной вставки, отмены и повтора текущая страница обновляется сразу, без устаревших списков;
- исправлено падение при закрытии главного экрана проекта с загруженной афишей;
- центр восстановления валидирует исходный проект, автосейв, атомарный `.bak` и архивные копии перед открытием;
- если автосейв новее или основной файл поврежден, Mezozoy показывает выбор проверенных копий и не перезаписывает исходник без явного `Ctrl+S`;
- новая стартовая библиотека проектов: команды создания и открытия, адаптивные карточки, логлайн, дата изменения и быстрый доступ к недавним `.mzoy`;
- афиша проекта в PNG, JPEG, BMP или GIF: изображение встраивается прямо в `.mzoy`, отображается на стартовой карточке и не теряется при переносе файла;
- выбор и удаление афиши доступны на карточке проекта и в `Разработка → Сценарий → Титульная страница`; на пустой обложке показан плюс, на готовой афише - кнопка с карандашом;
- меню `Разработка` оформлено как дерево проекта: первой строкой всегда идет название проекта, ниже расположены раскрывающиеся разделы персонажей, миров, сценария, локаций, референсов и связей;
- многодокументный проект: папки, сценарии, эпизоды, сезоны, титульные страницы, синопсисы, тритменты, планы, бит-листы, романы, комиксы, пьесы, аудиодрамы, заметки, ментальные карты и галереи референсов;
- единый объект сцены для сценария, карточек, поиска, импорта и экспорта;
- цельный сценарий открывается как основной режим редактора: все сцены идут подряд в одном тексте, разбитом на конечные страницы выбранного формата;
- типизированные абзацы и постоянные ID сцен связывают цельный текст с моделью проекта без невидимых символов;
- название сцены имеет один источник: первая строка сценария сразу синхронизируется с навигатором, правой панелью, карточкой и сохранённым `.mzoy`;
- сценарные элементы: заголовок сцены, описание действия, персонаж, ремарка, реплика и переход;
- форматирование этих элементов теперь работает прямо в цельном сценарии, применяется ко всему логическому абзацу и сохраняется вместе с проектом для редактора, F12 и PDF;
- умный `Enter`, циклический `Tab` и `Ctrl+1`...`Ctrl+6`; ремарка автоматически получает скобки и располагается под именем персонажа;
- операции сцены в списке: переименование, дублирование, копирование, вырезание, вставка, перестановка и удаление;
- глобальный проектный буфер `Ctrl+C` / `Ctrl+V` для сцен, карточек, разделов доски, персонажей, локаций, папок и документов;
- отмена и повтор проектных действий через `Ctrl+Z`, `Ctrl+Y` и `Ctrl+Shift+Z`; глубина истории от 0 до 1000 шагов задается в настройках;
- набор текста сценария остается нативной операцией редактора и не создает отдельный проектный шаг на каждый символ;
- карточная доска с режимами «Свободно», «Колонки» и «По порядку», бесконечными мировыми координатами, вписыванием всей истории в окно и синхронизацией выбора со сценарием;
- хронометраж рассчитывается по реально занятой части общей печатной раскладки: одна заполненная страница равна примерно одной минуте фильма;
- плавный масштаб доски к курсору: колесо сразу двигает камеру и быстро интерполирует остаток без ступенчатой задержки;
- карточки показывают номер, название, синопсис, длительность и статус;
- контекстное меню карточки: открыть в сценарии, переименовать, изменить синопсис, дублировать, переместить, заблокировать и удалить;
- история проекта: персонажи, локации, миры, референсы, связи персонажей и папки;
- глобальный поиск `Ctrl+Shift+F` и командная палитра `Ctrl+K`;
- импорт с предварительным просмотром и экспорт Fountain/TXT;
- единый предпросмотр, PDF и системная печать с титульным листом и пресетами `Hollywood / US Letter` и `A4`;
- полноценное русское меню настроек с категориями, темами, акцентными цветами, масштабом, автосохранением, поведением редактора и диагностикой доски.

## Горячие клавиши

- `Ctrl+S` - сохранить;
- `Ctrl+Shift+S` - сохранить как;
- `Ctrl+O` - открыть проект;
- `Ctrl+N` - новый проект;
- `Ctrl+K` - командная палитра;
- `Ctrl+Shift+F` - поиск по проекту;
- `Ctrl+I` - импорт Fountain/TXT;
- `Ctrl+Shift+E` - экспорт Fountain/TXT;
- `Ctrl+C` / `Ctrl+V` - скопировать / вставить выбранный проектный объект вне текстовых полей;
- `Ctrl+Z` - отменить последний проектный шаг;
- `Ctrl+Y` или `Ctrl+Shift+Z` - повторить отмененный проектный шаг;
- `F12` - предпросмотр конечных страниц, PDF и печать;
- `Ctrl+1`...`Ctrl+6` - формат текущей сценарной строки;
- `Tab` / `Shift+Tab` - следующий / предыдущий тип строки;
- `F2`, `Delete`, `Ctrl+X`, `Ctrl+D` в списке сцен - дополнительные действия со сценой;
- колесо мыши на доске - плавный масштаб к курсору;
- средняя кнопка мыши - панорамирование доски;
- двойной щелчок по карточке - открыть сцену;
- правая кнопка на доске - контекстное меню.

Глобальные команды не перехватывают `Ctrl+C`, `Ctrl+V`, `Ctrl+Z`, `Ctrl+Y`, `Ctrl+X`, `Ctrl+A`, `Delete` и `Enter`, когда фокус находится в редакторе или обычном текстовом поле.

## Данные и диагностика

- настройки: `%APPDATA%\Mezozoy\settings.json`;
- краш-лог: `%USERPROFILE%\Documents\Mezozoy\Mezozoy-crash.log`;
- проекты по умолчанию: `%USERPROFILE%\Documents\Mezozoy Projects`;
- автосохранение: рядом с проектом, файл `*.autosave.mzoy`;
- резервные копии: рядом с проектом, папка `Mezozoy Backups`.

## Ограничения альфы

- PDF создается через установленный системный принтер Microsoft Print to PDF;
- DOCX, FDX, облако и совместная работа пока не реализованы и не маскируются неработающими кнопками;
- ментальная карта хранится как тип документа, отдельный графовый редактор будет добавлен позднее;
- связи персонажей представлены списком связей; визуальная карта отношений еще не входит в 0.9;
- режим колонок выполняет автоматическую раскладку, а карточка запоминает колонку после переноса внутрь нее.

## Сборка

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипт собирает статический Windows EXE через LLVM/MinGW с `-Wall -Wextra -Wpedantic`, затем запускает внутренний набор проверок. CMake доступен как альтернативный путь сборки.

Установщик собирается установленным Inno Setup 6:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-installer.ps1
```
