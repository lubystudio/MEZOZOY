# Участие в разработке Mezozoy

1. Создайте fork репозитория и отдельную ветку для изменения.
2. Соберите проект командой `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1`.
3. Проверьте, что встроенные тесты завершились успешно.
4. Не добавляйте пользовательские проекты, настройки, резервные копии, EXE и содержимое `build`.
5. В pull request кратко опишите проблему, поведение после изменения и проведённые проверки.

Пожалуйста, сохраняйте нативный механизм перемещения окна Windows и совместимость файлов `.mzoy`.
